# Save a reference. Explore it in chat.

Paste a public link into **Add reference** and choose **Save reference**. The Studio saves it immediately and looks for a public cover. A cover and a playable preview are separate. If the same source is already saved, the Studio opens that entry with its existing notes and visibility.

Choose **Copy analysis request** and paste it into the editing chat for this Studio. The assistant inspects the source and enriches the same reference. If the video is unavailable, attach a local copy in chat when you paste the request. Reference options → Edit details lets you revise the title, creator or original note later.

## Explore the techniques

Open the reference and choose a technique to play its excerpt in the same player. **Back to full video** returns to your earlier position. Each row shows the technique family and time range. Earlier jump points remain under **More moments**. The creator and original source link appear under the reference title. **About this reference** holds analysis details, coverage limits and saved reference notes.

During analysis, the assistant saves each distinct, verified, reusable move as a playable example. Several timestamps can describe one move. Group related examples under an existing family and add a family when the behavior is distinct. The Studio presents the saved examples when you return from chat.

## Borrow a technique

**Borrow this technique** copies one exact excerpt for your editing chat. You can add direction beside the excerpt before copying. Save a note when you want that direction to travel with the example in future edits.

Use **+** to collect excerpts. In the full video, **Add moment** captures the current time and adds it to the same selection. Add a note beside the player if you like. The bottom bar counts the techniques and moments together. **Copy for chat** copies the whole selection immediately. **Review & add direction** lets you inspect the picks, edit a moment note or give direction to a specific excerpt. The two copy paths include the same items and notes.

The selection remembers each exact example, including two examples from the same family. Moment notes belong to the selection in this browser. Copying a selection does not create a saved library note.

## Remove or restore

Use **Remove this example** under **About this reference** while an excerpt is selected, or **Remove from library** in the full reference’s options. Restore an item from **Removed from library**. Its files and existing links are kept.

## Local data

Saving a link and copying a request are local actions. The Studio looks for a public cover using bounded HTTPS requests for declared og:image or twitter:image raster metadata. Cover retrieval uses public DNS validation, bounded redirects and response sizes, and no browser cookies. The chat handoff is where analysis and media access happen. Owner media and cover files stay in the installation.
